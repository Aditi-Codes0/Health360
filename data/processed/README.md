# Health 360 - Processed Data Directory

This directory stores cleaned, standardized, and analytically prepared datasets generated by the Python preprocessing pipeline.

## Processed Outputs
- **`clean_patient_data.csv`**: Patient-level dataset with validated clinical ranges, normalized categorical values, derived demographic bands (`age_group`), and clinical categories (`bmi_category`).
- **`data_quality_report.csv`**: Complete audit log recording raw row counts, cleaned counts, missing value handling, duplicate checks, and outlier profiling.
